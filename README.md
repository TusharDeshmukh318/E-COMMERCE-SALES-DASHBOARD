
# 🛒 E-Commerce Sales Dashboard

## 📌 Project Overview

The **E-Commerce Sales Dashboard** is an interactive data analytics project developed using **Power BI** to analyze and visualize e-commerce sales performance.

The dashboard transforms raw sales data into meaningful business insights by providing a clear view of **sales, revenue, profit, products, categories, customers, regions, and sales trends**. It is designed to help businesses understand their performance and make data-driven decisions.

## 🎯 Project Objective

The main objective of this project is to:

* Analyze overall e-commerce sales performance
* Track key business KPIs such as **Total Sales, Profit, Quantity, and Orders**
* Identify top-performing products and categories
* Analyze sales performance across different regions
* Understand monthly and yearly sales trends
* Identify profitable and underperforming areas
* Present business insights through an interactive dashboard

## 🛠️ Tools & Technologies

* **Power BI** – Dashboard development and visualization
* **Power Query** – Data cleaning and transformation
* **DAX** – Calculated measures and business metrics
* **Microsoft Excel** – Data source and preliminary data preparation

## 📊 Dashboard Features

The dashboard includes:

### 🔹 KPI Overview

* Total Sales
* Total Profit
* Total Orders
* Total Quantity Sold
* Average Sales / Order

### 🔹 Sales Analysis

* Sales by Month
* Sales by Year
* Sales by Category
* Sales by Product
* Sales by Region

### 🔹 Product Analysis

* Top-selling products
* Most profitable products
* Product/category performance

### 🔹 Regional Analysis

* Region-wise sales
* Region-wise profit
* Comparison of regional performance

### 🔹 Interactive Filters

Users can interact with the dashboard using filters and slicers such as:

* Date
* Region
* Category
* Product
* Customer

## 📈 Key Insights

The dashboard helps answer important business questions such as:

* Which products generate the highest sales?
* Which categories are most profitable?
* Which region performs the best?
* How do sales change over time?
* Which products contribute the most to revenue?
* Which areas require improvement?

## 🔄 Data Preparation Process

The project follows a basic data analytics workflow:

**Raw Data → Data Cleaning → Data Transformation → Data Modeling → DAX Calculations → Visualization → Business Insights**

### Data Cleaning & Transformation

Using Power Query, the data was prepared by:

* Removing duplicate records
* Handling missing values
* Correcting data types
* Cleaning column names
* Creating required calculated columns
* Preparing data for analysis

## 📐 Data Analysis

DAX measures were created to calculate important business metrics and KPIs.

Examples include:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity
* Average Sales
* Profit Margin

These measures were then used to create interactive Power BI visualizations.
